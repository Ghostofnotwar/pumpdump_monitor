# Формат алерта

Фактический формат генерируется `monitor.alert_caption()`.

```text
🟢 PUMP BTCUSDT

📈 +5.12% за 5 мин
💰 Цена: 71245.5 USDT
📊 Оборот 24ч: 123,456,789 USDT
🕯 Свечи: 5m · 14:32:15 UTC
Сигнал #1 за час · окно не равно ТФ свечей
Информационный сигнал, не инвестиционная рекомендация.
```

Для падения — `🔴 DUMP` и отрицательное изменение. Процент относится к скользящему окну тикеров, а не к последней свече. Номер считается по доставленным алертам этого чата/инструмента/направления за последний час.

Кнопки: **TradingView** и **Bybit**. Это ссылки на инструменты, не команды на сделку.

## График

- Реальные свечи и объём из публичного Bybit OHLCV.
- Volume SMA 9 — переключается.
- CVD proxy — переключается, по умолчанию выключен; оценка по OHLCV, не лента покупок/продаж.
- Профиль объёма — переключается, по умолчанию выключен; равномерное распределение объёма внутри диапазона каждой свечи.
- Последняя цена, окно движения, ТФ свечей и время UTC.

Последняя свеча может быть ещё не закрыта. Данных OI, ликвидаций, FVG, OB, ATR-score и крупных лотов в сообщении нет. Прежняя документация описывала желаемый формат, а не реализованные расчёты; фиктивные панели удалены.

## Ошибки и тест

Если график недоступен, отправляется тот же текстовый сигнал с пометкой. Отсутствующий по retention PNG не скрывает запись истории.

`/test` отправляет тестовый график BTCUSDT с явной маркировкой. Он не выдумывает цену или процент и не создаёт запись рыночного алерта.
